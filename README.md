# money-machine

## Step 1: frontend foundation

React + Vite workspace prototype with creator and business navigation.

Requires Node.js 22+. Run `npm ci` then `npm run dev`.

Build with `npm run build`. See [the Step 1 guide](docs/STEP_1.md) for file explanations, testing instructions, scope, and next steps.

## People-first redesign

The app now starts with searchable creator and business profiles instead of a dashboard. See [the social discovery guide](docs/SOCIAL_DISCOVERY.md) for features, source files, and limitations.
